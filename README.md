# Gopesh S | Software Engineer Portfolio

A premium, recruiter-focused personal portfolio website engineered for **Gopesh S**, B.Tech Information Technology student (2027 batch) at *Nandha Engineering College*.

Built using **pure HTML5, CSS3, and modern JavaScript (ES6+)** with zero external JS framework overhead, this portfolio delivers a fast, responsive, and interactive presentation of software engineering projects, internship experience, skills, and coding achievements.

---

## 🚀 Key Features

- **No Avatar / Hero Image**: Clean typographic focus featuring an interactive **IDE code block terminal** with floating technology badges.
- **Light & Dark Theme Toggle**: Built-in theme switcher with `localStorage` persistence and smooth CSS color transitions.
- **Dynamic Typing Animation**: Cycles through key engineering titles (*Software Engineer, Java Developer, Full Stack Developer, AI Enthusiast, Problem Solver*).
- **Project Filtering & Quick View Modal**: Interactive project category filter (All, Full Stack Web, Machine Learning, Future Innovations) with quick-view modal detail breakdowns.
- **Animated Stat Counters**: Scroll-triggered numeric counter animations highlighting 250+ DSA solved problems and project milestones.
- **Client-Side Contact Validation**: Real-time form validation with custom error states and animated toast notifications.
- **Official Resume Viewer & Generator**: One-click modal preview and resume download trigger.
- **SEO & ARIA Accessibility**: Full OpenGraph tags, semantic HTML5 structure, keyboard navigation support, and structured JSON-LD schema for recruiters.
- **100% GitHub Pages Compatible**: Works directly by opening `index.html` or hosting statically on GitHub Pages.

## 🌐 Deployment & Local Setup

### Option 1: Direct File Open
Simply open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** -> **Pages**.
3. Select `main` branch and `/root` directory.
4. Click **Save**. Your portfolio will be live at `https://<your-username>.github.io/<repo-name>/`.
